# Snipit.ru

*Репозиторий для идей, ошибок и вопросов по проекту [Snipit.ru](https://snipit.ru)*

**Текущая версия: 1.5.1**

## История изменений

### 1.5.1 — 30.07.2026

- Улучшен внешний вид раздела «Инструменты» и JSON Formatter.
- Исправлено отображение хлебных крошек, мобильного меню и переключателя темы.
- Подтверждение очистки JSON теперь отображается в фирменном окне Snipit.
- На главной странице добавлены отдельные карточки для публичных сниппетов и инструментов разработчика.
- Исправлены небольшие визуальные ошибки и улучшена мобильная версия.

### 1.5.0 — 30.07.2026

- Добавлен новый публичный раздел **«Инструменты»**, доступный без регистрации и авторизации.
- Добавлен **JSON Formatter** для форматирования, проверки, исправления и минификации JSON.
- Реализованы загрузка JSON из файла, вставка из буфера обмена, копирование и скачивание результата.
- Добавлен просмотр JSON в виде дерева и поиск по его содержимому.
- Поддержана работа с различными кодировками файлов.
- Все операции выполняются локально в браузере — данные не отправляются на сервер и не сохраняются.
- Добавлена полноценная мобильная версия инструмента.
- Улучшено SEO новых страниц.

### 1.4.1 — 30.07.2026

- Улучшена и стабилизирована авторизация через VK ID и Яндекс ID.
- Telegram больше не используется для входа и оставлен только для будущих уведомлений.
- Исправлено отображение способов входа и подключённых сервисов в профиле.
- Исправлены ошибки авторизации и привязки аккаунтов.

### 1.4.0 — 30.07.2026

- Добавлена возможность привязать несколько способов входа к одному профилю.
- Добавлена новая страница профиля с управлением подключёнными сервисами.
- Добавлена авторизация через Яндекс ID.
- Обновлена авторизация через VK ID.
- Улучшены безопасность, интерфейс и удобство авторизации.
